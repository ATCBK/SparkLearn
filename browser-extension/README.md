# SparkLearn 网页资料采集扩展

这个扩展用于把当前浏览器网页保存到当前登录账号的 SparkLearn“资源中心”，并触发后端 AI 解析，生成资料解析卡片和讲解稿。

## 本地安装

1. 启动 SparkLearn 后端，默认地址为 `http://127.0.0.1:8000`。
2. 打开 Chrome 或 Edge 的扩展管理页。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择本目录：`browser-extension/`。

## 使用方式

1. 打开一篇要保存的网页。
2. 如果只想保存局部内容，先选中文章正文。
3. 点击浏览器工具栏里的 SparkLearn 扩展。
4. 确认后端地址，使用 SparkLearn 手机号和密码登录扩展。
5. 点击“抓取并保存到资源中心”。
6. 回到 SparkLearn 网页端 `/generate?view=library`，在“资源中心”中查看解析卡片和讲解稿。

## 说明

- 优先保存用户选中的文本。
- 未选中文本时，会尝试抓取当前页面的 `article`、`main` 或正文可见文本。
- 抓取请求必须携带当前扩展账号的登录 Token，不会再保存到固定的 `single_user` 空间。
- Token 只保存在扩展本地存储中；修改后端地址后必须重新登录，避免将 Token 发送到其他服务。
- 当前版本面向本地开发环境，默认连接 `http://127.0.0.1:8000`。
