使用说明

1. 先配置模型与本地服务。
2. 如果需要本地 MCP，直接在 MCP Servers JSON 中填写 stdio/HTTP 配置。
3. 默认不启用沙箱；如果后续你要更严的限制，再单独打开。
4. 保存后如果本地服务已在运行，需要重启后生效。
