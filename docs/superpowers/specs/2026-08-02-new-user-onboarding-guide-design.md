# SparkLearn 新手任务式引导设计

## 背景

当前 SparkLearn 已有 `/onboarding` 学习画像采集流程，但新用户完成画像后进入主工作台时，仍不容易理解平台后续怎么用、每个模块分别解决什么问题，以及如何形成完整学习闭环。

本次设计面向首次登录或首次注册用户，在主工作台提供一次性“任务式新手引导”。引导不是单纯讲解功能，而是把用户带到真实动作里，帮助用户理解并完成 SparkLearn 的核心链路：

画像构建 → 路径规划 → 资源生成 → AI 互动 → 练习评测 → 学习报告 → 画像更新

## 目标

1. 首次登录或首次注册用户进入主工作台时，自动看到新手学习链路面板。
2. 面板用任务清单表达完整学习闭环，每一步包含价值说明、亮点小字和行动按钮。
3. 用户可以跳过、完成、稍后再看；完成或明确跳过后不再自动弹出，稍后再看只临时收起。
4. 保留“重看引导”入口，避免用户跳过后找不到说明。
5. 设计风格参考飞书、Notion、钉钉、Linear 等产品的 Getting Started 思路：任务驱动、进度清晰、操作入口明确、少量高亮提示，不做冗长说明页。

## 新手判定

本期采用用户确认的口径：首次登录或首次注册。

前端以本地存储作为轻量判定：

- `sparklearn_new_user_guide_seen:<userId>`：用户已看过或跳过新手引导。
- `sparklearn_new_user_guide_progress:<userId>`：用户在新手任务中的勾选进度。
- 当用户登录后进入 shell 主工作台，如果没有 `seen` 标记，则显示引导面板。
- 如果无法读取 `userId`，退化使用 `sparklearn_new_user_guide_seen:anonymous`，避免页面报错。

说明：后端如果后续提供用户首次登录字段，可替换本地判定；本期先保持前端闭环，降低改动范围。

## 入口与展示时机

### 自动入口

新手第一次进入 `/` 学习工作台时，在页面顶部 hero 下方显示“新手学习链路面板”。

### 手动入口

在主工作台保留一个轻量按钮：“新手引导”。用户点击后可重新打开面板。

### 跨页面策略

本期不做全站浮层 tour。用户点击任务按钮后跳转到对应页面，面板进度留存在本地；返回工作台时继续展示剩余任务。

这样可以避免引导遮挡复杂页面，也符合“先理解链路，再进入真实动作”的目标。

## 引导面板结构

面板包含三层信息：

1. 顶部摘要：告诉用户 SparkLearn 是一个个性化学习闭环，不是普通聊天工具。
2. 任务链路：7 个步骤按顺序展示，每一步有状态、标题、小字亮点、行动按钮。
3. 底部操作：开始第一步、稍后再看、跳过引导、全部标记已了解。

### 顶部摘要文案

标题：`从一次画像开始，跑完你的个性化学习闭环`

说明：`SparkLearn 会根据你的目标、基础和薄弱点，规划路径、生成资源、陪你互动练习，并把结果回写到学习画像里。`

亮点标签：

- `多智能体协作`
- `个性化路径`
- `资源自动生成`
- `练习与报告闭环`

按钮：`生成资源`

### 4. AI 互动

标题：`让 AI 导师带你拆问题`

亮点：`形成持续迭代的个性化学习系统。`

## 交互细节

1. 面板首次自动展开。
2. 用户点击某一步行动按钮时，该步骤标记为“已了解”，再跳转页面。
3. 用户点击“稍后再看”时，仅收起当前面板，不写入 `seen`，下次进入仍可展示。
4. 用户点击“跳过引导”时，写入 `seen`，下次进入不再自动展示。
5. 用户点击“全部标记已了解”或完成最后一步时，写入 `seen`。
6. 工作台上的“新手引导”按钮可强制展开面板，即使 `seen` 已存在。
7. 任务项支持键盘聚焦，按钮具备清晰可访问名称。

## 视觉设计

整体采用工作台内嵌面板，不使用大面积遮罩。

视觉参考：

- 飞书新用户任务卡：强调任务进度和下一步动作。
- Notion Getting Started：用清晰清单降低陌生感。
- Linear onboarding：少量高亮、强行动按钮、信息密度克制。

布局要求：

- 桌面端：顶部摘要在左，进度与链路任务在右或下方；7 个任务以两列或单列时间线展示。
- 移动端：单列卡片，按钮不溢出，面板不遮挡底部导航。
- 不使用大面积渐变背景，不做营销式 hero；保持工作台工具感。
- 每一步突出标题，小字保持 12-13px，用于解释亮点而不是堆说明。

## 技术设计

新增组件：

- `frontend/src/components/onboarding/NewUserGuidePanel.tsx`

组件职责：

- 读取当前用户。
- 判断是否展示引导。
- 管理任务进度和 `seen` 标记。
- 渲染新手链路任务。
- 处理跳转、跳过、重看。

集成点：

- 在 `frontend/src/app/(shell)/page.tsx` 中引入面板。
- 在首页 hero 区域附近提供“新手引导”重看入口。

不改动：

- 不改后端接口。
- 不改变已有 `/onboarding` 画像采集流程。
- 不改学习主工作台 `/tutor` 的业务逻辑。

## 测试与验证

手动验证：

1. 清空本地 `sparklearn_new_user_guide_seen:*` 后进入 `/`，面板自动出现。
2. 点击任务按钮后，对应步骤被标记并跳转到正确页面。
3. 返回 `/` 后进度仍保留。
4. 点击“全部标记已了解”后刷新页面，面板不再自动出现。
5. 点击“新手引导”按钮后，面板可重新展开。
6. 移动端宽度下按钮、标题、小字不重叠。

自动验证：

- 补充 Playwright 用例覆盖首次展示、跳过后不再自动展示、重看入口可用。
- 运行 `npm run lint`。

## 风险与边界

1. 本期使用 localStorage 判断首次展示，同一账号换浏览器会再次出现；这是可接受的轻量方案。
2. 现有部分页面文案存在乱码，本期不处理全站乱码，只保证新增内容为 UTF-8 中文。
3. 若用户从登录后直接进入非首页，本期不会跨页弹出引导；下一次进入首页时展示。

## 验收标准

1. 首次进入工作台能看到任务式新手学习链路面板。
2. 面板完整呈现 7 步闭环，每一步都有大标题、小字亮点和行动按钮。
3. 用户可以跳转执行、稍后再看、跳过引导、全部标记已了解、重看引导。
4. 完成或跳过后不再自动干扰用户。
5. 新增内容在桌面端和移动端布局正常，无明显文字溢出或遮挡。
