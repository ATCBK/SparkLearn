# SparkLearn 小程序 UI 重构设计文档

> **日期**: 2026-06-09
> **分支**: fix/remerge-video-main
> **目标**: 重构小程序全部页面 UI，对齐 Web 端设计风格，不动功能逻辑

## 1. 设计目标

将当前小程序从"功能占位"状态升级为与 Web 端视觉体验一致的产品级 UI：
- 色彩、字体、间距、阴影系统完全对齐 Web 端 `globals.css`
- SVG 线性图标替代中文字符"图标"
- 自定义毛玻璃 Tab 栏
- 补充缺失子页面的 UI 骨架
- 添加微动效提升质感

## 2. 设计决策

| 决策项 | 结论 |
|--------|------|
| 图标方案 | 本地 SVG 线性图标（对标 Web Lucide） |
| 改造范围 | 全面翻新：全局样式 + 3 Tab + 全部组件 + 5 个子页面骨架 |
| Tab 栏 | 自定义图标 Tab 栏 + 毛玻璃效果 + 选中动效 |

## 3. 改造层次

### L1: 设计 Token
- 色彩、渐变、阴影、圆角全部取自 Web `globals.css`
- 新增 `--gradient-blue`、`--gradient-brand`、`--glass-bg`

### L2: 图标系统
- `src/assets/icons/` 下 20+ SVG 图标
- `Icon` 组件支持 6 色 3 尺寸

### L3: 全局样式
- 页面网格纹理背景
- 自定义导航栏
- 页面过渡动效

### L4: Tab 栏
- 毛玻璃白色背景
- SVG 图标 + 选中态蓝色 + 缩放动效

### L5: 页面改造
- AI助学页：蓝色渐变小卡 + 2x2 快捷网格 + 对话列表
- 刷题页：主题选择器 + 题量分段控件 + 答题卡片 + 结果卡
- 我的页：身份卡 + 四宫格统计 + 画像摘要 + 复盘入口

### L6: 子页面骨架
- 答题记录、错题本、收藏题、设置、隐私协议

### L7: 微动效
- 页面渐入、卡片按压、Tab 弹跳、进度条过渡

## 4. 不变的部分
- 所有 `.tsx` 中的业务逻辑、状态管理、API 调用
- 路由配置（app.config.ts）
- 类型定义（types/）
- 工具函数（utils/）
- 服务层（services/）
