建议优先使用电脑浏览器打开网页端进行体验，以获得更完整、稳定的页面展示效果。

## 2. 关于演示视频时长

SparkLearn 的功能模块较多，覆盖了学习者画像构建、个性化路径规划、资源生成、学习互动、练习评测、反馈报告、画像更新等多个环节。由于展示内容较完整，演示视频中有部分内容可能超出规定时长。

这一点还请各位评委老师理解。我们希望通过演示视频尽可能完整地呈现平台的主要能力，也建议评委老师结合网页端实际体验进行评阅。

## 3. 关于 PPT 与 PDF 材料

考虑到不同设备可能使用 WPS、Microsoft Office 等不同软件打开 PPT，版本差异可能会影响字体、排版或动画效果。为了保证评阅材料显示一致，我们已将 PPT 同步转换为 PDF 文件，供各位评委老师参考和评阅。

如需查看原始 PPT，也可以使用随附的 PPT 文件；如遇到显示异常，建议优先查看 PDF 版本。

## 4. 关于 EXE 文件体验

项目材料中包含对应的 EXE 文件。建议评委老师下载并打开该文件，运行后查看项目中的相关内容。

使用 EXE 文件体验时，同样建议优先使用演示账号登录；如果评委老师希望自行注册账号，也可以正常使用。

## 5. 关于服务器接口与本地能力

平台已经部署到服务器，但部分功能会调用外部 API。若同一时间使用人数较多，或接口额度临时不足，可能出现调用失败、响应较慢等情况。遇到这类问题时，请随时联系我们，我们会及时协助处理。

另外，SparkLearn 项目中还有一些需要本地环境支持的能力，例如本地电脑控制相关功能。这类能力需要在本地部署后才能完整体验。

平台也集成了飞书相关能力。如果评委老师希望进一步体验飞书相关功能，也可以联系我们，我们会协助配置和演示。
