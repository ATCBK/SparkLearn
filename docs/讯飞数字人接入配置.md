# 讯飞数字人接入配置

## 当前 SDK

你已经放入的是「超拟人数字人交互」Web SDK：

```text
frontend/public/libs/avatar-sdk-web_3.2.3.1002/
```

项目现在默认加载：

```text
/libs/avatar-sdk-web_3.2.3.1002/esm/index.js
```

不需要 Windows 数字人 SDK。

## .env 配置

在项目根目录 `.env` 里补充或修改：

```env
XF_DH_ENABLED=true
XF_DH_APP_ID=你的APPID
XF_DH_API_KEY=你的APIKey
XF_DH_API_SECRET=你的APISecret
XF_DH_AVATAR_ID=你的数字人形象ID

XF_DH_SDK_URL=/libs/avatar-sdk-web_3.2.3.1002/esm/index.js
XF_DH_SERVER_URL=讯飞文档中的WebSocket服务地址

XF_DH_WIDTH=720
XF_DH_HEIGHT=405
XF_DH_SCALE=1.15
XF_DH_MOVE_H=0
XF_DH_MOVE_V=-95
XF_DH_TRANSPARENT=true

XF_DH_TTS_VOICE=x4_lingxiaoxuan_oral
XF_DH_TTS_SPEED=50
XF_DH_TTS_PITCH=50
XF_DH_TTS_VOLUME=100
XF_DH_STREAM_PROTOCOL=webrtc
```

如果你在讯飞控制台看到场景参数，也可以继续填：

```env
XF_DH_SCENE_ID=你的sceneId
XF_DH_SCENE_VERSION=你的sceneVersion
```

## 参数去哪找

- `XF_DH_APP_ID`：讯飞开放平台应用详情里的 APPID。
- `XF_DH_API_KEY`：同一个应用详情里的 APIKey。
- `XF_DH_API_SECRET`：同一个应用详情里的 APISecret。
- `XF_DH_AVATAR_ID`：数字人形象 ID，需要在超拟人数字人交互的形象/场景配置或接入示例代码里找。
- `XF_DH_SERVER_URL`：超拟人数字人交互文档里的 WebSocket 服务接口地址，不是 SDK 下载页地址。
- `XF_DH_TTS_VOICE`：数字人说话音色，不确定时先用默认值，后续按讯飞音色列表替换。

## 启动注意

改完 `.env` 后，需要重启后端和前端开发服务。

现在页面只完成「数字人渲染」。下一步接播报时，会调用 SDK 实例的 `writeText()`，数字人会按照回答文本说话并产生口型。
