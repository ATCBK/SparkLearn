# 讯飞数字人接入配置

## 当前 SDK

你已经放入的是「超拟人数字人交互」Web SDK：

```text
frontend/public/libs/avatar-sdk-web_3.2.3.1002/
```

项目现在默认加载：

```text
/libs/avatar-sdk-web_3.2.3.1002/esm/index.js
```

不需要 Windows 数字人 SDK。

## .env 配置

在项目根目录 `.env` 里补充或修改：

```env
XF_DH_ENABLED=true
XF_DH_APP_ID=你的APPID
XF_DH_API_KEY=你的APIKey
XF_DH_API_SECRET=你的APISecret
XF_DH_AVATAR_ID=你的数字人形象ID

XF_DH_SDK_URL=/libs/avatar-sdk-web_3.2.3.1002/esm/index.js
XF_DH_SERVER_URL=wss://讯飞控制台给出的数字人服务地址/v1/interact
XF_DH_SIGNED_URL_TTL_SEC=240
XF_DH_MEMORY_TTL_SEC=1800

XF_DH_WIDTH=720
XF_DH_HEIGHT=405
XF_DH_SCALE=1.15
XF_DH_MOVE_H=0
XF_DH_MOVE_V=-95
XF_DH_TRANSPARENT=true

XF_DH_TTS_VOICE=x4_lingxiaoxuan_oral
XF_DH_TTS_SPEED=50
XF_DH_TTS_PITCH=50
XF_DH_TTS_VOLUME=100
XF_DH_STREAM_PROTOCOL=webrtc
```

如果你在讯飞控制台看到场景参数，也可以继续填：

```env
XF_DH_SCENE_ID=你的sceneId
XF_DH_SCENE_VERSION=你的sceneVersion
```

## 参数去哪找

- `XF_DH_APP_ID`：讯飞开放平台应用详情里的 APPID。
- `XF_DH_API_KEY`：同一个应用详情里的 APIKey。
- `XF_DH_API_SECRET`：同一个应用详情里的 APISecret。
- `XF_DH_AVATAR_ID`：数字人形象 ID，需要在超拟人数字人交互的形象/场景配置或接入示例代码里找。
- `XF_DH_SERVER_URL`：超拟人数字人交互文档里的 WebSocket 服务接口地址，不是 SDK 下载页地址。
- `XF_DH_TTS_VOICE`：数字人说话音色，不确定时先用默认值，后续按讯飞音色列表替换。

`XF_DH_SERVER_URL` 必须是绝对 `wss://` 地址，而且要与本地 SDK 对应的产品、区域和应用权限一致。`/vmss` 这类浏览器代理路径不能用于后端签名。

`XF_DH_SCALE=1.15` 是常用的初始标定值，不是固定要求。形象过大时逐步调小，附件里的测试占位值 `0.15` 也会被正常读取。

## 安全接入方式

`.env` 只由 FastAPI 后端读取，不能提交到 Git，也不能把 APPID、APIKey 或 APISecret 写入 `NEXT_PUBLIC_*`、前端源码或浏览器存储。

前端只访问两个接口：

- `GET /api/num-person/digital-human/config`：获取形象、画布、TTS 和 SDK 路径，不返回 APPID、APIKey、APISecret 或原始服务地址。
- `POST /api/num-person/digital-human/session`：在登录态下获取短期签名地址，响应带 `Cache-Control: no-store`，默认 240 秒后失效。

当前附件值按测试占位配置处理。如果以后真实凭据被发到聊天、文档或日志中，应立即在讯飞控制台轮换，再更新部署环境的 `.env`。

## 启动注意

改完 `.env` 后，需要重启后端和前端开发服务。验证顺序如下：

1. 打开视频播放页，确认数字人画面进入“已就绪”状态。
2. 点击“开启声音”，允许浏览器恢复音频播放。
3. 把视频播放到 20 至 30 秒后提问“这里是什么意思”。
4. 确认视频自动暂停，文字回答只出现一次，数字人只播报一次。
5. 播报中再次提问，确认旧播报被打断。
6. 在浏览器 Network 中确认配置响应没有 APIKey、APISecret 和原始服务地址。
7. 离开视频页，确认数字人声音和连接停止。

数字人连接或播报失败不会中断文字问答；页面会显示非阻塞提示，用户仍可继续学习。
