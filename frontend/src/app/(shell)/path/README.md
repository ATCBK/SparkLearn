# 个性化学习路径 + 甘特图

## 功能概述

本模块实现了个性化学习路径的可视化展示，支持两种视图模式：

1. **卡片视图**：传统的阶段路径回路，以卡片形式展示学习节点
2. **甘特图视图**：时间轴形式展示学习任务，支持进度管理

## 甘特图功能

### 核心功能

1. **时间轴展示**
   - 支持日/周/月三种缩放级别
   - 显示今日线标记
   - 周末特殊标记

2. **任务条**
   - 根据阶段显示不同颜色（补弱=红色、达标=蓝色、目标=绿色）
   - 显示学习进度
   - **拖拽左侧边缘**：调整开始日期
   - **拖拽右侧边缘**：调整结束日期
   - Hover 显示详细信息

3. **左侧节点列表**
   - 与甘特图双向联动
   - 显示每个节点的进度条
   - 显示预计时间范围
   - **完成按钮**：点击左侧圆形单选按钮标记完成
   - **完成样式**：删除线 + 灰色字体

4. **任务详情面板**
   - 显示任务详细信息
   - 进度滑块调整
   - 点击日期可直接编辑
   - 快捷操作按钮

### 视觉风格

- 圆角卡片：`rounded-[14px]`
- 边框颜色：`border-[#E5EAF2]`
- 主题色：`#2563EB`
- 阶段颜色：
  - 补弱：`#EF4444`（红色）
  - 达标：`#2563EB`（蓝色）
  - 目标：`#16A34A`（绿色）

## 使用方式

### 切换视图

在页面右上角有"卡片"和"甘特图"两个按钮，点击即可切换视图。

### 查看任务详情

1. 点击左侧节点列表中的节点
2. 或点击右侧甘特图中的任务条
3. 底部会显示任务详情面板

### 调整任务日期

1. 在甘特图中**拖拽任务条左侧边缘**调整开始日期
2. 在甘特图中**拖拽任务条右侧边缘**调整结束日期
3. 或在任务详情面板中**点击日期**直接编辑

### 标记任务完成

1. 点击左侧节点列表中节点左侧的**圆形按钮**
2. 已完成的节点显示**删除线 + 灰色字体**
3. 再次点击可取消完成状态

### 缩放时间轴

在甘特图右上角有"日"、"周"、"月"三个按钮，点击切换缩放级别。

### 快速定位今天

点击工具栏中的"今天"按钮，自动滚动到今日位置。

## 数据模型

### GanttTask

```typescript
interface GanttTask {
  id: string;
  nodeId: string;
  title: string;
  phase: '补弱' | '达标' | '目标';
  phaseId: number;
  startDate: string;
  endDate: string;
  duration: number;
  progress: number;
  status: 'pending' | 'in_progress' | 'completed' | 'blocked';
  estimatedHours: number;
  difficulty: 1 | 2 | 3 | 4 | 5;
  priority: 'high' | 'medium' | 'low';
  dependencies: string[];
  isCriticalPath: boolean;
  nodeIndex: number;
}
```

### GanttPlan

```typescript
interface GanttPlan {

```

## Hook 使用

```typescript
import { useGanttData } from './hooks/useGanttData';

function MyComponent() {
  const gantt = useGanttData(phases, {
    initialZoom: 'week',
    dailyHours: 2,
  });

  // 访问甘特图数据
  console.log(gantt.allTasks);
  console.log(gantt.overallProgress);
  console.log(gantt.stats);

  // 操作甘特图
  gantt.updateProgress(taskId, 50);
  gantt.selectTask(taskId);
  gantt.setZoom('day');
}
```

## 注意事项

1. 甘特图数据是基于路径节点自动生成的
2. 默认每日学习时长为 2 小时
3. 第一个节点默认为"进行中"状态
4. 达标阶段的任务默认标记为关键路径
5. 所有时间操作都基于本地时间
