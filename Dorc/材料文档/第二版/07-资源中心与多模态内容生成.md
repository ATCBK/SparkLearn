# SparkLearn 资源中心与多模态内容生成

## 1. 文档定位

本文档说明 SparkLearn 资源中心、多模态资源生成、资源预览下载、质量评估、视频生成和代码评测能力。该文档可用于介绍项目的内容供给能力和学习资产沉淀机制。

## 2. 资源中心定位

资源中心是 SparkLearn 的学习资产库。所有由 AI 生成、教师分发、社区导入、学习发现导入、浏览器插件采集的内容，都可以沉淀为资源。

资源中心解决的问题：

- 学习资料不再是一次性回答。
- 多模态内容统一管理。
- 资源可预览、下载、复用和继续讲解。
- 资源使用情况可反哺画像和路径。

## 3. 资源类型

| 类型 | 标识 | 说明 |
| --- | --- | --- |
| 文档 | `document` | 讲义、知识总结、步骤说明 |
| PPT | `ppt` | 演示文稿结构或文件 |
| 思维导图 | `mindmap` | 知识结构梳理 |
| 题集 | `quiz` | 练习题和解析 |
| 阅读材料 | `reading` | 深度阅读内容 |
| 代码案例 | `code` | 编程题、样例和评测 |
| 视频 | `video` | AI 讲解视频 |
| 播客 | `blog` | 音频讲解或播客稿 |
| 学习发现 | `discovery` | 从外部搜索导入 |
| 网页资料 | `web_material` | 浏览器插件采集网页 |

## 6. 生成接口流转

### 6.1 请求

`POST /api/resources/generate`

```json
{
  "type": "code",
  "prompt": "生成一个 FastAPI 路由练习案例",
  "profile": {
    "knowledgeLevel": "基础",
    "weakPoints": ["接口设计"]
  }
}
```

### 6.2 SSE 响应

```text
event: progress
data: {"stage":"started","resource_id":"res_001","progress":5}

event: progress
data: {"stage":"generating","resource_id":"res_001","progress":35}

event: text
data: {"content":"# FastAPI 路由练习","resource_id":"res_001"}

event: done
data: {"resource_id":"res_001","resource":{"id":"res_001","status":"completed"}}
```

### 6.3 后端处理

1. 创建资源 ID。
2. 根据资源类型选择生成器。
3. 对于 PPT、视频等长任务，先返回进度。
4. 对文本类资源，流式返回内容片段。
5. 生成完成后写入 PostgreSQL 资源元数据和文件存储。
6. 返回完成事件。

## 7. 星辰 Agent 平台资源生成

星辰 Agent 平台负责承接资源型任务，例如文档、思维导图、题集、阅读材料和代码案例。SparkLearn 本地后端负责：

- 组装画像上下文。
- 选择资源类型。
- 调用星辰 Agent 平台。
- 接收流式结果。
- 提取链接和正文。
- 保存资源。
- 失败时生成本地兜底内容。

材料口径中统一描述为“星辰 Agent 平台资源生成链路”。

## 8. PPT 生成

相关接口：

PPT Schema 包含：

| `/api/video/resources/{resource_id}/download/audio` | GET | 下载音频 |
| `/api/video/resources/{resource_id}/download/srt` | GET | 下载字幕 |
| `/api/video/resources/{resource_id}/download/mp4` | GET | 下载视频 |
| `/api/video/resources/{resource_id}/share` | POST | 分享视频 |

### 9.2 视频事件

```text
event: progress
data: {"stage":"script","progress":25,"message":"正在生成脚本"}

event: artifact
data: {"kind":"timeline","url":"/api/video/resources/vid_001/timeline"}

event: done
data: {"resource_id":"vid_001","resource":{}}
```

### 9.3 视频兜底

- 视频脚本生成失败返回 `VIDEO_SCRIPT_ERROR`。
- 视频生成失败返回 `VIDEO_GENERATION_FAILED` 和 `retryable`。
- MP4 不存在时提供明确包下载兜底，不伪装已有 MP4。
- TTS 失败时可回退本地或浏览器语音链路。

## 10. 代码资源评测

`POST /api/resources/code/evaluate/{resource_id}`

请求：

```json
{
  "question": "实现一个 FastAPI GET 接口",
  "hint": "使用 @router.get",
  "studentCode": "..."
}
```

响应：

```json
{
  "correct": true,
  "result": "正确",
  "reason": "代码定义了 GET 路由并返回 JSON"
}
```

兜底：

- 仅 `code` 类型资源允许评测。
- 代码为空返回 400。
- 模型评测失败时可使用规则检查给出基础反馈。

## 11. 资源质量评估

`POST /api/resources/{resource_id}/quality-evaluate`

评估维度：

- 画像匹配度 `fit`。
- 清晰度 `clarity`。
- 练习价值 `practice`。
- 优先级 `priority`。

响应：

```json
{
  "label": "较适合",
  "summary": "资源适合当前学习阶段",
  "advice": "建议配合练习题使用",
  "dimensions": [
    {
      "key": "fit",
      "label": "画像匹配",
      "score": 88,
      "level": "high",
      "detail": "匹配薄弱点：接口设计"
    }
  ]
}
```

## 12. 前端交互

资源中心前端主要交互：

- 类型筛选。
- 搜索。
- 折叠资源列表。
- 统一预览区。
- 下载。
- 删除。
- AI 讲解。
- 质量评估。
- 代码评测。
- 视频播放。
- 网页资料分析卡片。

前端将不同资源类型映射到不同预览逻辑，避免所有资源都用纯文本承载。

## 13. 兜底策略

| 场景 | 兜底 |
| --- | --- |
| 生成服务失败 | 本地模板内容 |
| SSE 中断 | 保留已生成片段，允许重试 |
| 外部链接预览失败 | 展示资源正文 |
| PDF 渲染失败 | 返回明确错误信息 |
| 下载源不存在 | 返回 404，不生成假链接 |
| 视频任务不存在 | 返回 `VIDEO_JOB_NOT_FOUND` |
| 资源为空 | 展示空状态和重新生成入口 |

## 14. 材料可复用表达

SparkLearn 将 AI 生成内容沉淀为可管理的学习资产，而不是一次性聊天回答。资源中心统一承载文档、PPT、思维导图、题集、代码案例、视频、播客、学习发现和网页资料，并支持预览、下载、质量评估、代码评测和继续讲解，形成可持续复用的个性化资源库。

## 15. 接口联动矩阵（可直接进答辩）

| 触发入口 | 后端主接口 | 回调/事件 | 落盘与复用 |
| --- | --- | --- | --- |
| `/generate` 页面生成文档 | `POST /api/resources/generate`（SSE） | `progress/text/error/done` | 写入 `resources_index.json`，并可加入学习路径/任务 |
| Tutor 中“继续讲解该资源” | `POST /api/tutor/chat`（会携带 `resource_id`） | 资源上下文加载事件 | 以 `resource_id` 串联历史讲解 |
| 社区内容导入 | `POST /api/forum/posts/{id}/import-resource` | 资源创建返回 | 进入资源中心并同步标签 |
| 学习发现导入 | `POST /api/info-stream/import-resource` | 直接落库返回 | 可再次通过 `POST /api/resources/recommendations/list` 推荐 |
| 视频风格定制 | `POST /api/video/polish` | `result` JSON | 供 `/api/video/jobs` 的脚本输入 |
| 下载/分享 | `GET /api/video/resources/{resource_id}/download/...`、`POST /api/video/resources/{resource_id}/share` | 无需 SSE | 产物可用于外部分享和复用 |

### 15.1 错误处理闭环

- `generate` 在 Coze 超时或报错时，仍会返回 `error` 事件，但 SSE 不会 500 终止，界面保留已输出版。
- `resource not found` 优先检查 `resource_id` 与索引文件一致性，再次回退到用户资源列表刷新。
- 下载失败时前端做二次兜底：先 `download`，再尝试 `download/pdf`，再返回明确报错，不返回伪造文件。
- PPT 资源若外部服务不可用，`content` 回退为结构化占位模板，仍保留资源记录可继续学习（可标记 `needs_regenerate`）。

### 15.2 运行时状态机

1. `created`（资源定义）  
2. `generating`（星辰 Agent 平台执行）  
3. `sse_progress`（中间事件）  
4. `done`（落盘成功）  
5. `failed`（失败可重试）  
6. `deprecated`（被新版本替换）

这个状态链路可在汇报时直接说明资源生命周期闭环可追踪、可回放、可续接讲解。
