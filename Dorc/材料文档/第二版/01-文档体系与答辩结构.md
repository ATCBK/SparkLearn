# 第二版文档体系与写作结构

## 目的
这版 12 篇文档的目标是：**一次性说明系统全貌**，并且能支持你后续写“项目说明书 + 答辩PPT + 验收材料”。

## 2.1 文档清单与职责

- `00-SparkLearn项目总览与材料口径`：项目边界、技术口径、统一术语。
- `01-文档体系与答辩结构`：你当前要问的“重写框架”，定义每章写什么。
- `02-个性化学习闭环设计`：从画像到任务、到评测闭环。
- `03-多智能体协作与星辰Agent平台`：Tutor 研讨会 + MCP 工具协作。
- `04-A2UI与AG-UI智能交互设计`：前端可观测事件和交互映射。
- `05-知识库RAG与可信回答机制`：检索、证据、置信度、反幻觉。
- `06-记忆系统与学习数据流转`：working/episodic/semantic 三层记忆 + 数据落库。
- `07-资源中心与多模态内容生成`：文字/思维导图/测验/视频资源流水线。
- `08-学习发现与网页资料采集`：外部内容来源到资源库的流转。
- `09-前后端与数据库技术架构`：前端适配器、后端路由、数据库和日志。
- `10-多端部署与运行方案`：开发、演示、生产与迁移清单。
- `11-测试验证与项目可交付说明`：验收标准和高风险场景。

## 2.2 写作规范
- **每章都要有“输入 -> 处理 -> 输出 -> 失败处理”四段**。
- 术语按 00 章定义，不再写“扣子”或“sqlnet”，统一为：
  - 星辰Agent平台
  - PG SQL
- 所有流式接口给出事件名，不只给最终接口。
- 涉及数据写入的流程，必须标注“谁写、写入什么、何时落盘”。

## 2.3 与评审最相关的关系图（建议口述）
- 一句话：`用户请求 + 画像 + 课程知识 + 外部检索 + 工具结果 -> 结构化事件 -> 可靠输出 -> 回写记忆`。
- 强调：Tutor 的每次输出都可回放成事件时间线（AGUI/A2UI/SSE）。

## 2.4 这版要回答的五个问题
1. 为什么这个系统不是单聊 AI，而是学习平台？
2. 为什么回答可信？
3. 为什么能演示“可解释交互”？
4. 出错了怎么办？
5. 迁移/部署与维护是不是清晰？

## 2.5 你可以直接套用的汇报顺序
`00 -> 02 -> 05 -> 04 -> 03 -> 06 -> 07 -> 09 -> 11 -> 10`，再按项目阶段补 `08`。
