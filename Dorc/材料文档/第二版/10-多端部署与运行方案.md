# SparkLearn 多端部署与运行方案

## 1. 文档定位

本文档说明 SparkLearn 的 Web、后端、PostgreSQL、Electron 桌面端、微信小程序、浏览器扩展和 MCP 的部署运行方案。该文档用于对外说明项目具备工程落地和多端运行能力。

## 2. 部署形态

SparkLearn 支持多种部署形态：

| 形态 | 说明 | 适用场景 |
| --- | --- | --- |
| 本地开发部署 | 前端、后端、数据库分别启动 | 开发调试 |
| Web 服务部署 | 前端和后端部署到服务器 | 线上演示或教学环境 |
| Electron 桌面端 | 本机托管前端和后端 | 私有化、本机能力、低门槛试用 |
| 微信小程序 | Taro 构建微信小程序 | 移动端轻量学习 |
| 浏览器扩展 | Chrome/Edge 加载扩展 | 外部网页资料采集 |

## 3. 环境变量

后端从项目根目录 `.env` 读取配置。关键配置包括：

- 应用配置：`APP_NAME`、`APP_VERSION`、`DEBUG`。
- PostgreSQL 配置：数据库地址、端口、用户名、密码、库名。
- 讯飞星火配置：App ID、API Key、API Secret、模型地址。
- 星辰 Agent 平台配置：API 地址、Token、Bot 路由配置。
- Embedding 配置：Embedding API 地址和密钥。
- TTS 配置：语音合成服务参数。
- 视频生成配置：视频模型、TTS、超时和兜底策略。
- MCP 配置：服务超时、工具超时。
- OSS/SMS 配置：短信和对象存储参数。

材料口径中不展开密钥值，只说明由环境变量注入。

## 4. 后端运行

后端技术栈：

- Python。
- FastAPI。
- Uvicorn。
- PostgreSQL。

典型启动命令：

```powershell
cd D:\Project_building\SparkLearn
python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000 --reload
```

健康检查：

```text
GET /health
```

响应：

```json
{
  "ok": true
}
```

启动流程：

1. 加载环境变量。
2. 配置日志。
3. 配置 Windows 事件循环策略。
4. 初始化 PostgreSQL 数据表。
5. 注册路由。
6. 开始监听请求。

## 6. PostgreSQL 部署

PostgreSQL 负责保存核心业务数据。部署要求：

- 创建 SparkLearn 数据库。
- 创建应用用户。
- 配置连接地址。
- 初始化表结构。
- 开启必要 JSONB 支持。

迁移思路：

1. 准备 PostgreSQL 实例。
2. 配置 `.env`。
3. 启动后端自动初始化表结构。
4. 导入历史数据。
5. 验证画像、资源、Tutor、练习和教师端接口。

兜底：

- 数据库连接失败时后端启动报错并输出日志。
- 迁移前保留备份文件。
- 关键表初始化采用幂等建表策略。

## 7. Electron 桌面端

### 7.1 定位

Electron 桌面端用于：

- 一键启动本地服务。
- 承接本机能力。
- 开放本地 stdio MCP。
- 提供 StudyBuddy 配置入口。

### 7.2 启动命令

```powershell
cd D:\Project_building\SparkLearn\desktop
npm install
npm run dev
```

### 7.3 打包命令

```powershell
npm run pack
npm run dist
```

打包目标：

- Windows NSIS 安装包。

### 7.4 桌面端运行流程

1. 用户启动 SparkLearn。
2. Electron 主进程检查前端和后端服务。
3. 拉起本机服务。
4. 渲染进程加载 Web 页面。
5. 用户配置本地模型、MCP 和工具参数。

### 7.5 桌面端兜底

- 服务端口占用时提示用户。
- 后端启动失败时查看日志。
- 本地 MCP 命令失败时记录错误。
- Web 端禁用本地 stdio MCP，桌面端开放。

## 9. 浏览器扩展部署

### 9.1 安装方式

1. 启动 SparkLearn 后端。
2. 打开 Chrome 或 Edge 扩展管理页。
3. 开启开发者模式。
4. 加载 `browser-extension/` 目录。
5. 打开网页并点击扩展采集。

### 9.2 默认连接

默认连接本地后端：

```text
http://127.0.0.1:8000
```

### 9.3 兜底

- 后端不可达时提示检查地址。
- 页面内容无法读取时提示选中文本。
- 保存失败时保留当前采集内容，允许重试。

- 描述。
- endpoint。
- 认证头。
- 超时时间。

### 10.2 stdio MCP

- command。
- args_json。
- env_json。
- startup_timeout_ms。

## 11. 日志与排查

常见日志：

- 后端请求日志。
- 后端错误日志。
- 前端开发服务器日志。
- Electron userData 日志。
- MCP 测试错误。
- 视频生成任务错误。

常见问题：

| 问题 | 排查 |
| --- | --- |
| 后端无法启动 | 检查 Python 依赖、端口、数据库连接 |
| 前端无法访问接口 | 检查后端地址和 CORS |
| SSE 无响应 | 检查代理是否缓冲流式响应 |
| PostgreSQL 连接失败 | 检查 `.env`、账号、网络 |
| 小程序构建失败 | 检查 Taro CLI 和依赖安装 |
| MCP 调用失败 | 检查命令、参数、超时和桌面端环境 |

## 13. 部署口径与风险控制（答辩）

### 13.1 关键环境隔离

1. 本地开发：允许 `single_user_id` 与 SQLite 模式，便于快速调试。  
2. 演示/准生产：切换 `.env` 为 PostgreSQL，开启完整审计与权限。  
3. 桌面端：额外提供本机 MCP 与本地服务管理能力，避免浏览器 CSP 限制。  

### 13.2 回滚与恢复

- 服务起不来：优先检查 `backend/.env`、端口占用、数据库连接；回退到上一个可用配置即可恢复。  
- 任务失败：视频/生成任务重试不删除历史记录，可再次触发生成。  
- 文件目录错乱：依据 `backend/data/` 快照恢复 `resources_index`、`task_progress`、`learning_events`。  
- 前端加载失败：切回兼容构建版脚本并保留默认路由配置。  

### 13.3 交付前检查

| 检查项 | 命令 | 通过判据 |
| --- | --- | --- |
| 后端健康 | `python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000 --reload` | `/health` 返回 `{\"ok\": true}` |
| 前端运行 | `npm run dev` | `localhost:3000` 可打开并加载 `/tutor` |
| 桌面端构建 | `npm run dist`（desktop） | 产物生成且可安装 |
| 小程序构建 | `npm run build:weapp`（miniapp） | 编译产物成功 |
| 数据库连接 | `.env` + 健康日志 | 无持续重连错误 |
