# SparkLearn 学习发现与网页资料采集插件

## 1. 文档定位

本文档说明 SparkLearn 的学习发现、外部内容导入、浏览器网页资料采集插件和网页资料解析能力。该文档可用于介绍项目如何把外部内容转化为可复用学习资产。

## 2. 学习发现定位

学习发现不是传统信息流，而是面向学习目标的外部资源发现入口。它围绕关键词、主题和学习阶段，从外部内容中发现视频、代码仓库、论文、技术文章等资料，并允许用户导入个人资源库。

它解决的问题：

- 学习者需要外部资料，但搜索成本高。
- 搜到的资料通常只是一次性浏览，无法沉淀。
- AI 推荐内容需要与个人画像和资源中心打通。

## 3. 学习发现接口

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/api/info-stream/sources` | GET | 获取发现来源 |
| `/api/info-stream/search` | GET | 按关键词搜索外部资料 |
| `/api/info-stream/recommendations` | GET | 获取推荐内容 |
| `/api/info-stream/bookmark` | POST | 收藏发现内容 |
| `/api/info-stream/import-resource` | POST | 导入为资源 |
| `/api/info-stream/bookmarks` | GET | 收藏列表 |

## 4. 搜索流程

1. 用户在 `/info-stream` 输入关键词。
2. 前端请求 `/api/info-stream/search`。
3. 后端根据来源类型执行搜索或构造推荐。
4. 返回结构化结果。
5. 前端按视频、代码、论文、文章等类型展示。
6. 用户可收藏或导入资源中心。

搜索响应示例：

```json
{
  "items": [
    {
      "id": "disc_001",
      "title": "FastAPI 官方入门教程",
      "summary": "介绍路由、请求参数和响应模型",
      "url": "https://example.com/fastapi",
      "source": "article",
      "tags": ["FastAPI", "后端"],
      "reason": "匹配当前接口设计薄弱点"
    }
  ]
}
```

## 5. 导入资源流程

`POST /api/info-stream/import-resource`

请求：

```json
{
  "title": "FastAPI 官方入门教程",
  "summary": "介绍路由、请求参数和响应模型",
  "url": "https://example.com/fastapi",
  "source": "article",
  "tags": ["FastAPI", "后端"]
}
```

处理流程：

1. 后端接收外部内容元数据。
2. 生成 `discovery` 类型资源。
3. 写入资源中心。
4. 记录资源使用事件。
5. 返回资源对象。

响应：

```json
{
  "id": "res_discovery_001",
  "title": "FastAPI 官方入门教程",
  "type": "discovery",
  "status": "completed",
  "sourceUrl": "https://example.com/fastapi",
  "content": "介绍路由、请求参数和响应模型"
}
```

## 6. 浏览器网页资料采集插件

### 6.1 插件定位

浏览器扩展用于把用户正在浏览的网页直接保存到 SparkLearn。它和学习发现不同：

- 学习发现是平台内搜索和推荐。
- 浏览器插件是用户在外部网页中主动采集。

两者最终都会进入资源体系。

### 6.2 插件使用流程

1. 用户打开外部网页。
2. 如果只想保存局部内容，可先选中正文。
3. 点击浏览器工具栏中的 SparkLearn 扩展。
4. 插件读取标题、URL、选中文本或页面正文。
5. 提交到后端 `POST /api/tutor/files/web-capture`。
6. 后端保存资料并生成解析卡片。
7. 用户回到 SparkLearn 的 Tutor 文件或资源中心查看。

### 6.3 正文提取策略

插件提取顺序：

1. 优先使用用户选中文本。
2. 若没有选中文本，尝试读取 `article` 标签。
3. 再尝试读取 `main` 标签。
4. 最后提取页面可见文本。

兜底：

- 文本过短时提示用户选择正文。
- 页面无法访问 DOM 时提示手动复制。
- 后端不可用时提示检查本地服务地址。

## 7. 网页采集接口

`POST /api/tutor/files/web-capture`

请求示例：

```json
{
  "title": "FastAPI 路由教程",
  "url": "https://example.com/fastapi-routing",
  "content": "FastAPI 使用装饰器声明路由...",
  "selected": false
}
```

响应示例：

```json
{
  "id": 32,
  "filename": "FastAPI 路由教程",
  "source_url": "https://example.com/fastapi-routing",
  "mime_type": "text/html",
  "size_bytes": 12000,
  "analysis": {
    "summary": "本文介绍 FastAPI 路由定义和参数处理。",
    "key_points": [
      "APIRouter 用于模块化组织接口",
      "路径参数和查询参数分别用于不同场景"
    ],
    "audience": "适合正在学习 Python Web 后端的学习者",
    "learning_method": "建议先读摘要，再生成接口练习题",
    "lecture_script": "这篇文章可以分成三个部分理解..."
  }
}
```

## 8. 网页资料解析

后端解析网页资料时生成：

- 摘要。
- 关键知识点。
- 适合人群。
- 推荐学习方式。
- AI 讲解稿。
- 原文内容。

解析流程：

1. 清洗网页文本。
2. 截断超长内容。
3. 调用 AI 生成结构化分析。
4. 校验字段格式。
5. 缺失字段使用规则兜底。
6. 保存为 Tutor 文件和资源中心的 `web_material` 类型。

## 9. 资源中心联动

网页资料进入资源中心后：

- 类型显示为“网页资料”。
- 展示来源 URL。
- 展示分析卡片。
- 支持查看原文。
- 支持继续 AI 讲解。
- 可纳入 Tutor 文件上下文。

资源类型映射：

```json
{
  "type": "web_material",
  "sourceType": "web_capture",
  "sourceUrl": "https://example.com/fastapi-routing"
}
```

## 10. 与 Tutor 的联动

用户可以在 Tutor 中基于网页资料提问：

1. 用户选择网页资料。
2. Tutor 对话请求携带 `file_ids`。
3. 后端读取网页原文和分析卡片。
4. AG-UI 展示文件上下文加载步骤。
5. Tutor 基于网页资料回答。
6. 可信回答链路输出来源引用。

## 11. 与学习画像的联动

网页资料和学习发现会反哺画像：

- 高频导入某类主题，说明学习兴趣或目标变化。
- 多次导入同类资料，可提升对应知识点优先级。
- 资源使用行为可影响学习偏好。
- 网页资料中的知识点可成为后续练习主题。

## 12. 兜底策略

| 场景 | 兜底 |
| --- | --- |
| 插件无法提取正文 | 提示用户选中文本后重试 |
| 后端服务不可达 | 提示检查后端地址 |
| 网页内容过短 | 返回资料质量不足提示 |
| AI 解析失败 | 使用规则摘要、关键词和默认讲解稿 |
| URL 不合法 | 拒绝保存并提示 |
| 资源导入重复 | 可复用已有资源或创建新版本 |
| 原网页失效 | 保留已采集正文，不影响学习 |

## 13. 材料可复用表达

SparkLearn 将外部内容获取从“搜索后浏览”升级为“发现、采集、解析、沉淀、继续学习”的闭环。学习发现负责平台内推荐与导入，浏览器插件负责外部网页主动采集，二者最终都进入资源中心和 Tutor 上下文，使外部资料成为可复用、可讲解、可评测的学习资产。

## 14. 交互与数据一致性

### 14.1 学习发现响应模型

`/api/info-stream/recommendations` 的响应建议包含两个层面：

- `source`：来源（`video`、`paper`、`github`、`article`）；
- `recommendation`：按画像加权后的候选内容。

后端通过并发抓取/检索后聚合，失败的单一来源不会导致全局失败，保证用户侧至少返回一组降级候选。

### 14.2 收藏与导入事务顺序

1. `search` 结果先按来源聚合；
2. 点击收藏时执行 `POST /api/info-stream/bookmark`，幂等重复触发会取反；
3. 点击导入时执行 `POST /api/info-stream/import-resource`；
4. 导入后立即更新 `resources_index.json`；
5. 接口返回 `resource_id`，并可在 `/generate` 与 `Tutor` 中继续使用。

### 14.3 插件与后端契约

`POST /api/tutor/files/web-capture` 要求：

- `title` 非空；
- `url` 符合 URL 规范；
- `content` 长度超出限制时截断；
- 解析异常时返回 `analysis` 默认字段，避免前端空状态。

兜底处理策略为：  
插件侧先尝试选中文本，后退到正文提取；后端侧先 AI 分析，后退到规则摘要并保留原文。
