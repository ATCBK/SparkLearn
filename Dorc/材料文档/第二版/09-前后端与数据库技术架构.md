# SparkLearn 前后端与数据库技术架构

## 1. 文档定位

本文档说明 SparkLearn 的前端、后端、数据库、API、SSE、认证、数据表和工程结构。材料中统一使用 PostgreSQL 数据库口径。

## 2. 技术栈

| 层级 | 技术 |
| --- | --- |
| 前端 Web | Next.js 16、React 19、TypeScript、App Router |
| UI 与可视化 | Tailwind CSS、lucide-react、ECharts、React Markdown、Three.js |
| 后端 | FastAPI、Pydantic、Uvicorn |
| 数据库 | PostgreSQL |
| AI | 讯飞星火大模型、星辰 Agent 平台、Embedding、TTS |
| 流式交互 | Server-Sent Events |
| 桌面端 | Electron、electron-builder |
| 小程序 | Taro、React、微信小程序 |
| 测试 | pytest、ESLint、Playwright |

### 4.2 API 层

前端 API 层位于：

- `frontend/src/lib/api/types.ts`
- `frontend/src/lib/api/real.ts`
- `frontend/src/lib/api/mock.ts`
- `frontend/src/lib/api/index.ts`

职责：

- 定义前端业务类型。
- 封装 fetch 请求。
- 统一认证头。
- 读取 SSE。
- 转换字段命名。
- 将后端资源转换为前端 Resource。
- 合并 A2UI 和 AG-UI 事件。

### 4.3 SSE 读取

前端对流式接口执行：

1. 发起 fetch。
2. 读取 ReadableStream。
3. 按 SSE 协议解析 `event` 和 `data`。
4. 按事件类型回调页面状态。
5. 连接结束后清理加载状态。

异常处理：

- JSON 解析失败跳过坏事件。
- 网络中断保留已收到文本。
- 后端返回 error 事件时展示错误。

## 6. 数据库架构

### 6.1 数据库口径

第二版材料统一采用 PostgreSQL 作为数据库。数据库承载：

- 用户和认证。
- 学习画像。
- 任务和路径。
- 资源元数据。
- Tutor 角色、会话、消息、文件。
- 知识库文件和分片。
- 练习题、记录、错题、收藏。
- 教师端学生、科目、广播。
- 社区帖子、评论、附件、互动。
- MCP 服务配置。
- 分享链接。

### 6.2 关键数据域

| 数据域 | 主要内容 |
| --- | --- |
| 用户域 | 用户、手机号、登录状态 |
| 画像域 | 学习目标、薄弱点、偏好、阶段 |
| 学习域 | 路径、节点、任务、贡献、掌握度 |
| 资源域 | 资源类型、内容、文件路径、状态 |
| Tutor 域 | 角色、会话、消息、文件、网页资料 |
| 知识库域 | 文件、分片、Embedding、检索元数据 |
| 练习域 | 题目、提交、解析、错题、收藏 |
| 教师域 | 学生、科目、诊断、广播和资料 |
| 社区域 | 帖子、评论、点赞、收藏、附件 |
| 工具域 | MCP 服务、工具列表、调用状态 |

### 6.3 PostgreSQL 设计要点

- 使用结构化表保存事实数据。
- JSONB 保存灵活元数据，例如画像扩展、资源分析、消息事件。
- 时间字段使用统一时间戳。
- 资源文件路径与元数据分离。
- 业务表按用户 ID 关联。
- 长文本和生成物可存储在文件系统，数据库保存索引。

## 7. 统一接口响应

### 7.1 普通响应

普通接口返回 JSON 对象，例如：

```json
{
  "items": [],
  "page": 1,
  "page_size": 20
}
```

### 7.2 错误响应

后端使用 HTTP 状态码和 detail：

```json
{
  "detail": "resource not found"
}
```

常见状态：

- 400：请求参数错误。
- 401：未认证。
- 404：资源不存在。
- 500：服务内部错误。
- 502：外部服务或渲染失败。

### 7.3 SSE 响应

SSE 用于：

- Tutor 对话。
- 资源生成。
- 视频任务。

事件类型：

- `meta`
- `progress`
- `text`
- `sources`
- `search_results`
- `mcp_call`
- `agui`
- `a2ui`
- `confidence`
- `trust_meta`
- `citations`
- `artifact`
- `done`
- `error`

## 9. 认证与权限

认证接口：

- `GET /api/auth/check-phone/{phone}`
- `POST /api/auth/sms/send`
- `POST /api/auth/sms/login`
- `POST /api/auth/sms/register`
- `GET /api/auth/me`
- `POST /api/auth/logout`

认证流程：

1. 用户输入手机号。
2. 请求验证码。
3. 登录或注册。
4. 后端返回 token。
5. 前端保存 token。
6. 后续请求带 `Authorization`。

兜底：

- 验证码限流。
- 验证码过期。
- 未登录时回到登录页。

## 10. 兜底与稳定性

| 层级 | 策略 |
| --- | --- |
| 前端 | 局部失败不阻断页面、展示空状态和重试 |
| 后端 | 参数校验、异常捕获、HTTP 状态码 |
| 数据库 | 初始化表结构、默认数据、迁移脚本 |
| AI | 模板兜底、规则兜底、可信度降级 |
| SSE | error 事件、保留部分输出 |
| 文件 | 文件不存在返回 404，外部链接失败回退正文 |

## 11. 材料可复用表达

SparkLearn 采用 Next.js 16 + FastAPI + PostgreSQL 的前后端分离架构，通过 SSE 支撑 AI 流式交互，通过 PostgreSQL 管理画像、路径、资源、消息、知识库和社区等核心数据，并通过星辰 Agent 平台、讯飞星火、MCP、RAG 和记忆系统组成可扩展的智能学习后端。

## 12. 接口与体系执行边界（答辩复用）

### 12.1 统一响应边界

- 资源查询、列表、建议类接口优先返回结构化分页结果；写入类接口返回成功确认和主键。
- 列表 API 必须携带分页参数或 `limit`，避免全量返回。
- 非法参数返回 400 并附带字段级 `detail`，用于前端提示。
- 认证失败返回 401，返回 `detail` 并触发登录恢复。

### 12.2 事务边界

- 核心路径（画像、路径、任务、练习、资源）优先进入数据库事务，保证状态可回放。
- 非核心日志（学习事件、视频事件、资源访问）采用追加写文件，避免阻塞主流程。
- 多端共用 `/api/*` 接口，不同端通过能力配置决定可见能力（如桌面端允许 stdio MCP）。

### 12.3 PostgreSQL 与文件协作

- 文档口径统一：主数据库为 PostgreSQL（PG SQL）；文件与 JSONL 索引用于可追踪审计与离线素材。
- 外部服务产物先建立任务/资源草稿，再经落库确认，最后才对外返回可下载状态。
- 迁移场景下可将数据库实现切到 PostgreSQL，接口层保持稳定，减少验收联调成本。
