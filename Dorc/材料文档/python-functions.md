## 1. 什么是函数
函数是一段可以重复使用的代码，用来完成某个具体任务。
比如“求和”“判断奇偶”“打印问候语”都可以写成函数。

## 2. 为什么要用函数
- 减少重复代码
- 让程序结构更清晰
- 方便维护和修改
- 提高代码复用性

## 3. 函数的基本语法
```python
def 函数名(参数):
    代码块
    return 返回值
```

## 4. 一个最简单的例子
```python
def say_hello():
    print("你好")
```
调用：
```python
say_hello()
```

## 5. 带参数的函数
参数就是传给函数的数据。
```python
def greet(name):
    print("你好，" + name)
```
调用：
```python
greet("小明")
```

## 6. 带返回值的函数
返回值表示函数处理后的结果。
```python
def add(a, b):
    return a + b
```
调用：
```python
result = add(3, 5)
print(result)
```

## 7. print 和 return 的区别
`print` 是把结果显示出来。
`return` 是把结果交还给调用函数的地方继续使用。

## 8. 注意事项
- 函数名要见名知意
- 缩进必须正确
- 没写 `return` 时默认返回 `None`
- 参数个数要和调用时保持一致

## 9. 总结
函数是 Python 中最基础也最重要的工具之一。
学会函数，才能更好地组织代码，写出清晰、可复用的程序。
