# 08 数据库与文件存储设计
文档状态：已完成
版本口径：当前代码实现（2026-07-08）
写作口径：仅记录系统基础信息、功能实现、接口、数据流和存储设计。

## 1. 存储设计说明
- 数据库负责保存用户、画像、掌握度、Tutor、知识库、Agent、教师端、社区、信息流、MCP、分享和短信等结构化数据。
- 文件存储负责保存用户上传文件、生成资源、视频产物、日志、事件数据和本地配置。
- 数据库初始化主入口是 `backend/app/db.py` 的 `init_db()`。

## 2. 数据库类型说明
- SQLite 实现位于 `backend/app/db.py` 和 `backend/app/db_sqlite.py`，适合本地开发和桌面端内嵌运行。
- PostgreSQL/PolarDB 适配位于 `backend/app/db_postgresql.py`，用于生产级关系数据库环境。
- 配置项位于 `backend/app/config.py`，包括 db_type、db_host、db_port、db_name、db_user、db_password、db_ssl_mode 和 db_path。

## 14. 数据初始化与迁移
- `init_db()` 创建所有基础表和索引。
- `_ensure_student_columns()` 补齐 students 的 phone、avatar、last_login_at 等字段。
- `_ensure_knowledge_columns()` 补齐知识库 subject 和 embedding 字段。
- `_ensure_tutor_message_columns()` 补齐消息 meta_json 字段。
- `_ensure_tutor_file_columns()` 补齐文件来源、状态、分析结果和更新时间字段。
- `_seed_mastery()`、`_seed_tutor_workspace()`、`_seed_teacher_subjects()` 和 `_seed_forum_posts()` 写入默认数据。

## 15. 数据读写约束
- 主键字段包括文本 ID 和自增整数两种形式。
- 唯一约束用于单用户 Agent 宠物、贡献日期、点赞收藏、浏览历史、教师科目名称和广播投递。
- 索引用于用户维度查询、时间倒序查询、任务查询、消息查询和插件启用状态查询。
- 时间字段统一使用 ISO 字符串或数据库时间戳。
- JSON 字段以文本或 JSONB 保存，用于兼容 SQLite 和 PostgreSQL。
