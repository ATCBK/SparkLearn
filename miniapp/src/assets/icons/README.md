# 图标说明

本目录需要放置以下图标文件，用于小程序 TabBar 显示。

## 必需图标

### 首页图标
- `home.png` - 未选中状态
- `home-active.png` - 选中状态

### 知识图谱图标
- `graph.png` - 未选中状态
- `graph-active.png` - 选中状态

### 刷题图标
- `practice.png` - 未选中状态
- `practice-active.png` - 选中状态

### 个人中心图标
- `profile.png` - 未选中状态
- `profile-active.png` - 选中状态

## 图标规格

- **尺寸**：81 x 81 像素
- **格式**：PNG
- **背景**：透明
- **颜色**：
  - 未选中状态：#999999
  - 选中状态：#1890FF

## 推荐图标库

你可以从以下图标库下载或自定义图标：

1. **Iconfont**：https://www.iconfont.cn/
2. **Flaticon**：https://www.flaticon.com/
3. **Icons8**：https://icons8.com/

## 图标设计建议

- 使用简洁的线性图标风格
- 保持图标一致性
- 确保在不同背景下清晰可见
- 选中和未选中状态要有明显区别

## 快速获取图标

如果暂时没有设计资源，可以使用以下方式：

1. 使用在线图标生成工具
2. 使用 emoji 作为临时方案
3. 使用纯色圆形作为占位符

## 图标命名规范

- 使用小写字母
- 使用连字符分隔单词
- 使用有意义的名称
- 例如：`home.png`、`graph-active.png`
