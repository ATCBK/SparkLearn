# Changelog

本文件记录 SparkLearn 小程序的所有重要更改。

## [1.0.0] - 2026-06-05

### 新增

#### 核心功能
- 首页：用户信息、学习数据概览、功能入口、今日学习、热门知识点、快速开始
- 知识图谱：分类选择、知识点列表、掌握度可视化、详情查看
- 智能刷题：练习配置、多题型支持、实时反馈、答案解析
- 个人中心：用户信息、数据统计、功能菜单、学习分析、设置

#### 辅助功能
- 练习结果：正确率展示、统计数据、评价反馈、操作按钮
- 练习历史：历史记录列表、统计展示、加载更多
- 题目详情：题目信息、选项列表、正确答案、解析内容
- 知识点详情：知识点信息、掌握度、统计数据、相关知识点
- AI 对话：聊天界面、消息列表、输入区域、快捷问题
- 设置：通用设置、数据管理、帮助与反馈、关于信息

#### 技术实现
- Taro 3 + React + TypeScript 项目结构
- Zustand 状态管理
- 统一的 API 服务封装
- 完整的 TypeScript 类型定义
- 通用组件库（Loading、Empty、Card、Button、ProgressBar）
- 图表组件（BarChart、PieChart）
- SCSS 样式系统（变量、Mixins、BEM 规范）

### 技术栈

- 框架：Taro 3.15.0
- UI 库：React 18
- 语言：TypeScript 5.0
- 样式：SCSS
- 状态管理：Zustand 4.4
- 构建工具：Webpack 5
- 目标平台：微信小程序

- 部分功能需要后端 API 支持
- 深色模式尚未实现

### 后续计划
